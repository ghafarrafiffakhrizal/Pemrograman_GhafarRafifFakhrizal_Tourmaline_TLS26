**Kelompok:** Tourmaline

## Deskripsi Repository

Repository ini berisi penyelesaian Tugas Pemrograman Dasar TLS 2026 yang terbagi menjadi dua fase utama:

### 1. Fase 1: Perancangan Logika (PDF)
Dokumen perancangan logika algoritma yang berisi:
* **Problem 1 (The Last Astronaut):** *Pseudocode* dan penjelasan logika penyelesaian simulasi eliminasi astronot melingkar dengan pembaruan aturan nilai $K$ secara dinamis.
* **Problem 2 (Alien-In-The-Middle):** *Flowchart* dan penjelasan logika sistem enkripsi sandi rahasia (*cipher*) berbasis pergeseran posisi alfabet dari huruf sebelumnya.

### 2. Fase 2: Implementasi C++ (.cpp)
Kode sumber implementasi C++ yang dibuat menggunakan library standar `<iostream>` dan fungsi buatan manual (*user-defined function*):
* **`problem1.cpp`**: Program untuk menghitung dan menampilkan urutan astronot yang tereliminasi serta menentukan astronot terakhir yang bertahan.
* **`problem2.cpp`**: Program untuk menguraikan dan menghasilkan pesan terenkripsi berdasarkan aturan sandi pergeseran huruf.
